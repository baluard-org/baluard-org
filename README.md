# baluard-org

The Baluard website: homepage, security white paper, and the apt/dnf package repository, served by GitHub Pages at https://baluard.app.

## Layout

- `site/`: Zola source templates, content, and configuration.
- `index.html`: Homepage generated by local `just build`.
- `security.html`: The security white paper, rendered from markdown by `tools/render.py`.
- `repo/`: The apt and dnf package repository, generated by `just repo-stage` in the main repository. Committed on purpose for GitHub Pages git serving.
- `assets/`: Vector logos, app icons, and brand fonts.
- `CNAME`: Custom domain (`baluard.app`).
- `justfile`: Local development and build targets.

## Local Development & Build

No remote GitHub Actions CI minutes spent. Build locally with Zola and `just`:

```sh
just serve     # Start local preview on http://127.0.0.1:1111 with live reload
just build     # Build site with Zola and stage to root index.html and assets/
just check     # Verify internal links and templates
```

## Release Flow

From a checkout of `baluard-org/baluard` after `just release-sign dist`:

```sh
just repo-stage dist ../baluard-org/repo
cd ../baluard-org
python3 tools/render.py path/to/baluard/docs/security-white-paper.md security.html
just build
git add -A && git commit -m "release 0.1.0" && git push
```

## Notes

- `.nojekyll` keeps GitHub Pages serving the tree as-is.
- Each release adds ~17 MB of package binaries to this repository history.
